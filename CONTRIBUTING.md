# Contributing

Midwife Mesh is at concept stage. Technical and clinical feedback is welcome through GitHub Issues after BADEF enables and moderates them.

Please do not submit real patient records, identifiable case details, credentials, secret keys, unsafe medical instructions or unlicensed third-party code. Before contributing code, obtain agreement from the project maintainers on licensing and review procedures.

Suggested topics: LoRa feasibility, low-literacy Somali UI, acknowledgement reliability, referral workflows, data protection and secure open-source architecture.
