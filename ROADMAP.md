# Proposed 12-month roadmap (not work completed)

| Period | Planned milestones | Evidence to publish |
|---|---|---|
| Months 1–3 | Requirements, technical feasibility, approvals, initial UI, test with five midwives | Requirements, mockups, lab test logs, approved protocols |
| Months 4–6 | Train and equip 40 midwives, install relays/gateways, launch monitored pilot | Versioned code, deployment guides, network test results |
| Months 7–9 | Review alert reliability, improve coverage, refresher training, explore aggregate analytics | De-identified metrics and technical change logs |
| Months 10–12 | Independent evaluation, handover plan, open publication | Evaluation summary, code, manuals and release notes |

These are targets from the BADEF concept note. Progress should be updated only when milestones are actually achieved.
