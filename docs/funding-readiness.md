# UNICEF FemTech Ventures — eligibility and evidence gaps

**Call:** https://www.unicef.org/innovation/FemTechCall (deadline listed as 11 November 2026).

**Potential thematic alignment:** Maternal healthcare access and referral continuity in low-connectivity settings.

**Critical gaps (as of November 2026):**

- BADEF is described as a **nonprofit** in the concept note; UNICEF Venture Fund requires the submitting entity to be a private for-profit company.
- Aspire Graphics Ltd is described as a proposed technology partner, not automatically the applicant. Its registration and willingness to take contractual responsibility must be confirmed.
- UNICEF asks for a **functional prototype with initial testing results**. Midwife Mesh is at concept stage and does **not** meet that condition based on current evidence.
- A GitHub repository containing documentation does not substitute for a working prototype or initial test results.
- Open-source intentions are described, but no Midwife Mesh code has yet been released.

**Recommendation:** Treat this repository as transparent project preparation. Seek clarification from UNICEF about eligibility or pursue future calls/partnerships after developing and testing a demonstrable prototype. Never describe this repository as evidence of an operational solution.

Source: https://www.unicefventurefund.org/apply-funding
