# Safety, privacy and data protection — proposed controls

This project concerns sensitive maternal and newborn health events. No real patient data should ever be committed to GitHub or placed on a public dashboard.

The concept proposes no names or medical records over radio; messages would carry a code, location and danger sign. **A location combined with an event may still identify a person in a small community.** Pseudonymisation is not equivalent to anonymisation.

Before testing with real users, establish:

1. Clinical and safeguarding oversight, incident response and consent procedures.
2. Data protection impact assessment and lawful data processing arrangements.
3. End-to-end threat modelling, secure key provisioning, encryption review and device loss procedures.
4. Data minimisation, retention limits, role-based access and audit logs.
5. Aggregation and disclosure thresholds for any public metrics.
6. Approved fallback referral processes if radio or facilities fail.
7. Local regulatory review and relevant ethics approvals.

**Current status:** Proposed safeguards only; no security audit or clinical validation has been performed for Midwife Mesh.
