## Critical design decisions

Hardware compatibility, coverage and relay count; gateway power and staffing; secure identity and key management; alert retry and deduplication; offline UX; message retention; emergency escalation when acknowledgement fails; patient consent; data governance; clinical validation; local spectrum compliance; and accessibility testing.

No code or test results are represented as existing.
